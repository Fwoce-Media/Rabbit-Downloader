# Rabbit Downloader

A download manager for Windows, with a browser extension.

**[Download](../../releases/latest)** · Setup.exe or portable zip

## Features

- Several connections per file, with pause and resume
- Takes over the browser's downloads (Chrome, Edge, Firefox)
- Finds videos and sounds on web pages, with a Download button on videos
- HLS (.m3u8) videos, with a choice of quality
- Turns .ts videos into .mp4
- Torrents and magnet links
- Sorts files into Video, Music, Documents, Programs and more
- Speed limit and downloads at once
- Dark and light, in red, blue, green or yellow
- Runs in the tray
- Updates itself
